# Words at Rest — brand v2

Created 2026-10-08 with the built-in ImageGen tool. `master.png` is the original transparent generated artwork. Production derivatives are generated with `node scripts/export-brand.mjs`; the symbol is resized, not redrawn.

The mark represents a word-search grid and a selected diagonal path. It deliberately contains no letter so it cannot merge visually with the wordmark. Palette: moss, warm ivory and muted ochre. Header/footer wordmarks use live text with an italic “at”; clear space between icon and text is 14px on mobile, 16px at 640px, and 18px at 768px and wider. Symbol sizes: 36 / 40 / 44px.

## Generation prompt

The final master uses a second built-in edit pass, preserving the same composition while removing the initial mottling. Edit prompt: “Polish this logo into pristine flat-color production artwork. Preserve the exact existing concept, arrangement, rounded tile silhouette, six ivory dots and the diagonal selected-word capsule with its two round ends. Remove ALL mottling, dark blotches, paper texture, grain, gradients and illumination from the green tile, the dots and the gold path. Entire green tile must be one completely uniform solid color #3D5A45. Entire ivory dots one solid color #F4EFE6. Entire gold connected path one solid color #D5B178. Perfectly crisp smooth edges, no rough outlines or shadows. Transparent background outside the rounded square. Do not add any letters or symbols or presentation elements. Keep the icon centered and independently readable. One clean finished mark.” The generated image has subtle tonal variation; prompt color values describe intent rather than exact per-pixel guarantees.

Design ONE finished premium brand symbol for Words at Rest, a calm word-search puzzle website for adults and older readers. Deliver a single isolated logo mark only, NO lettering, NO W, NO typography, NO wordmark, NO presentation board. Transparent background. Strong distinctive silhouette, refined editorial identity, precise flat vector-like craftsmanship; NOT watercolor, NOT grainy texture, NOT 3D, no shadows. Concept: a compact softly rounded dark moss-green square tile, containing a very simple 3 by 3 puzzle pattern of generously spaced small warm ivory dots, with one confident diagonal capsule connecting the lower-left and upper-right positions in muted warm ochre, the selected-word path. The diagonal should feel gently rising and calm, be thick enough to survive at 16 pixels, and integrate naturally with the remaining dots. Deliberate balanced negative space, optical alignment, subtle bespoke irregularity in the rounded-square shape while keeping crisp edges. Outer shape solid moss green #3D5A45; inner dots ivory #F4EFE6; selected path warm ochre #D5B178. Avoid magnifying glasses, leaves, books, checkmarks, serif initials, detailed grids or small letterforms. Compact icon centered, occupies about 85 percent of a square canvas with transparent clear space around all sides. Must feel like a thoughtful independent puzzle publication, mature and warm, memorable at favicon sizes. The final output is production artwork, not a mockup.
